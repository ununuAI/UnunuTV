# CinematicShotSpec 合同

每个对象代表一个艺术镜头，不代表一次 API 请求。必须回答以下问题：

1. 叙事：镜头任务、故事节拍、切镜原因。
2. 状态：开场状态、触发、动作链、反应/转折、结束状态。
3. 调度：站位、路径、朝向、视线、手部、道具、接触面。
4. 摄影：景别、机位、角度、透视/焦段、构图、景深、焦点。
5. 运镜：起点、路线、速度曲线、启动点、停止点、叙事目的。
6. 灯光：可解释光源、方向、软硬、色温、反差、负补光、曝光保护。
7. 色彩：主/辅/点缀色、冷暖、饱和度、对比度、人物背景分离和前后镜连续性。
8. 表演：目标、潜台词、呼吸、停顿、声线、视线、眉眼、嘴角、下颌、肩膀、手、重心和微表情顺序。
9. 声音：对白口型、环境底、拟音、距离、混响、呼吸、静默、声音桥和音乐进入/退出原因。
10. 物理/VFX：受力、身体、布料、头发、接触、环境或特效状态。
11. 剪辑：入口、出口、轴线、屏幕方向和连续性。
12. 权威：必需资产、不得提前出现的信息和验收标准。

“电影级、8K、高级感”不能替代以上具体设计。全局技术时长不写进内容 Prompt；镜头只保留相对节拍和剪辑意图。只有模型明确支持时，编译器才输出内部时间槽。

## 分镜脚本审查门

分镜脚本只能在当前 StoryPacket 最新 Owner ACCEPT 后定稿。Owner 必须按完整顺序审，而不是孤立看单镜：逐镜核对 opening → trigger → action/reaction → ending、前后镜状态交接、人物/道具/伤势/空间不可逆状态、屏幕方向、揭示顺序、切镜动机、对白与总时长。局部镜头成立但相邻镜无法连接，仍为 REJECT。

Shot 不得通过对白 `intent`、摄影方向或表演注释挽救已被 Story 删除的错误台词。Story revision 删除一句对白后，所有 Shot 的 `dialogue`、`performance`、`sound`、`internalTimeSlots`、`continuityPlan` 与验收条件都必须同步移除，旧 Shot revision 自动失效。

每个 verdict 持久化到 target type `cinematic_shot_revision`、target ID `cinematic-shot:<shotId>:r<revision>`。一个 GenerationUnit 只有在所有 linked Shot 当前 revision 的最新 verdict 均为 `accepted` 时才可通过正式 preflight。任何 Shot 修改都会创建新 target；旧 revision 的 ACCEPT 不得继续授权图像/视频生成。同 revision 后写 REJECT 必须覆盖旧 ACCEPT 并使依赖 compilation stale。

## 技巧必须落成可验收字段

- 运镜不是“推拉摇移”的词汇堆叠。每次运动必须说明由哪个演员动作、视线变化或信息揭示触发，摄影机和演员路线分别记录，速度曲线必须包含启动、缓入/减速和停止，停止画面必须获得新的重要信息；没有叙事收益时允许固定机位，让调度和表演制造尺度变化。
- 焦点是独立的时序状态，不是 `lensFocus` 里一句“拉焦”。凡起止焦距面不同或出现拉焦/转焦，Shot 必须提供覆盖 t0 到终点的 `focusDistancePlan`，每个关键时间边界写明焦距米数、目标和插值；GenerationUnit 的 camera track 在相同边界必须逐点写同一焦距面。终点焦距必须与真实终点主体距离一致，例如贴镜擦幅不能继续锁在八米外背景。缺端点、目标矛盾、Shot/Unit 不一致或终点仍锁旧主体均在 Provider 前硬阻断。
- 空间连续性必须把入口/目标/出口命名成 screen zone，记录注意轴、带符号屏幕方向、髋肩与头部朝向、视线、道具、接触面及演员/摄影机各自路径。越轴必须先有可见再定位镜头或明确动机。
- 人物和场景一致性不能靠 Prompt 承诺。人物身份/体型/服装、场景几何/固定陈设/材质/光源、武器/伤势/破坏的不可逆状态都必须来自已接受权威和相邻镜差分审计。
- 手、脚、武器和接触面必须做逐节拍占用审计。同一肢体不得同时承担互斥动作；道具换手、脱手、拔出、折断、落地或回手都必须有可见过程。若 Story 已锁定物理方法，Shot 不得为了动作方便改写。
- 动作镜头必须记录目的与战术、优势交换，以及准备→接触→受力反应→恢复/新状态；复杂打斗先做代理调度或动作相位板，再记录发起者、接触点、载体、轨迹、命中、反应、伤势/武器/疲劳连续性和覆盖镜头。
- 剪辑必须记录切点动机、动作方向与速度匹配、交叠区、反应镜头、声桥和下一镜入口状态；完整候选仍需全时间线审片，不能用单张好看截图代替。
