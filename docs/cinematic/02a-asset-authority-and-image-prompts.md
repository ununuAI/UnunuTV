# 资产权威与图片 Prompt

资产权威解决“什么必须跨镜稳定”，故事板解决“这个生成单元如何组织画格或动作相位”。两者不能互相替代，也都不是每个项目的固定门禁。

## 风险路由

- 人物身份、换装、妆发、年龄变化、多人特写或跨集连续性需要 `CharacterAuthoritySet`。
- 复杂空间、路径、轴线、多机位、追逐或建筑连续性需要 `SceneAuthoritySet`。
- 证据、武器、产品、信物、复杂拿取或接触物理需要 `PropAuthoritySpec`。
- 低风险纯氛围实验可以完全没有资产权威。

每个权威对象保存风险等级、状态、参考资产、可验收视图、控制职责、非职责、验收标准和禁止改变项。只有 `accepted` 版本才可被声明为已接受权威；`candidate` 只是候选。

## AssetViewSpec

每个视图必须写明景别、角度、可见事实、背景、控制内容、非控制内容和是否必需。人物使用人物名，不转换成“主体1”。视图集合按风险设计，不固定为三视图、六视图或九宫格。

## 确定性图片协议

- `ununu.character.v2`：人物身份、身份锁、服化妆发、权威视图和禁止变化。
- `ununu.image.v2`：场景或道具的空间、材质、灯光、尺度、磨损、交互和权威视图。
- `ununu.storyboard.v2`：有序画格、镜头意义、动作相位、连续性锁和风格隔离。
- `ununu.storyboard.keyframe.v1`：一个艺术镜头的一个明确冻结时刻。只保留该时刻可见的主体状态、空间站位、视线/接触、摄影机与构图、景深/焦点、表演、光色和连续性事实。

`ununu.storyboard.v2` 与 `ununu.storyboard.keyframe.v1` 不可混用。前者可以描述一组有序画格或动作相位；后者只能输出一张满幅叙事帧，不得包含完整开场→动作链→结束状态、时长、时间槽、运镜路径、切镜承接、声音时间线或多个时态。节点 ID、媒体 ID、导演台 capture 对象、camera snapshot、revision、时间戳和 Provider 参数只进入结构化 Envelope，不进入内容 Prompt。

单帧参考图使用一行一个短映射：`参考图N「权威素材名」 = 本帧语义别名。` 富 Token 与最终 payload 图片顺序必须一致。`controls`、`doesNotControl` 与来源 lineage 保存在 `ReferenceBinding`，不把长篇职责说明重复进可见 Prompt。GPT Image 2 在模型能力预检阶段阻断第 6 张参考图；必要时把已验收的多人物身份图本地合成为可追溯的身份合集，或只选择本帧确实可见且承担控制职责的权威图。

内容 Prompt 与图片 Provider 参数分离。比例、分辨率、模型和数量只进入 `CinematicImageGenerationParameters`。最终 payload 中真实存在的参考图片才可获得“参考图N”，编号严格来自 payload 顺序。

图片参数中的请求尺寸是 Provider 选择提示，不等于回传文件必须逐像素同宽同高。若上游最长边受 2K 上限约束并把结果归一到约 1K 档，必须同时记录 requested/actual dimensions，但不能仅因两者不完全相等而拒绝或制造技术告警。验收应检查：实际文件没有越过注册的 Provider 上限、像素量足够承担本板件职责、主体与空间细节可审、可见构图满足声明的横竖幅/画面关系。只有当精确比例本身被 Owner 锁定，或下游交付/合成明确要求该比例时，算术比例偏差才是阻断项。

故事板编译必须声明网格、画格编号和代理人物画风不进入最终成片。ComfyUI JSON、节点、模型路径和自定义节点不进入任何活动合同或 Provider payload。
